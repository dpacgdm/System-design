# Answer Keys

Learner-facing modules and retention tests contain **questions only**.

Worked analyses live here. Opening a key before attempting the drill invalidates your self-score.

## Layout

```text
answers/
  Retention-Tests/     Week-NN Answers.md
  Week-0N-.../         <Same title as learner file> Answers.md
  Week-08b-.../        ...
  Week-15-Mock-Interviews/
  Week-15b-Behavioral-SRE-Leadership/
  Week-15c-SRE-LLD/
  Week-16-Final-Mastery/
  Ops-Sims/
```

## Rules

1. Never copy expert analysis back into learner files.  
2. Prefer appending to an existing Answers file over creating duplicates.  
3. Standalone “Worked Answers” from early weeks also live under the matching `answers/Week-*/` folder.  
4. `tools/split_expert_answers.py` helps extract co-located blocks — it is **not** a quality score.
